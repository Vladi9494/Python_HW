# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

## Инструкция по запуску тестов для формирования отчета Allure
 
1. Перейти в рабочую директорию:
 ``` cd 10_lesson
 ```
2. Эта команда запустит все тесты и сохранит результаты в директорию "allure-result"
(появляется папка "allure-result"):
 ```python -m pytest --alluredir=allure-result
 ```

## Инструкция по просмотру сформированного отчета Allure

1. Эта команда запустит локальный сервер, конвертирует результат в отчёт
   и откроет отчет в браузере:
 ```allure serve allure-result
 ```
2.  эта команда генерирует результат в отчёт (появляется папка "allure-report"): 
 ```allure generate allure-result
 ```
3. С помощью этой команды можно просмотреть отчёт:
 ```allure open allure-report
 ```
 В отчете Allure вы увидите:
   - **Название теста**: `Тестирование сайта магазина`.
   - **Описание теста**: Тест проверяет корректность работы сайта магазина с различными операциями по заказу товаров.
   - **Шаги теста**:
     - Открытие страницы сайта магазина.
     - Ввод данных для авторизации.
     - Добавление товаров в корзину.
     - Проверка товаров в корзине.
     - Проверка товаров в корзине.
     - Переход в корзину.
     - Нажать кнопку "checkout".
     - Заполнение формы (оформления заказа)"checkout" личными данными.
     - Чтение со страницы итоговой стоимости заказа.
     - Проверка итоговой стоимости.

   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.
